Security · Tooling · Postmortem

Coldcard RNG Defect + HWI → Maintenance Mode

  • Coldcard branded "Don't Trust. Verify." — never audited the seed-generation path
  • Since Mar 2021: hardware TRNG silently disabled (MICROPY_HW_ENABLE_RNG=0); Yasmarang software PRNG ran instead
  • Seed looked valid; entropy was not — on-chain losses in the ~$100M+ range
  • Error 1: Source-available ≠ audited (restrictive license ≠ open-source scrutiny)
  • Error 2: Workflow security ≠ seed security — SE/PSBT reviewed; entropy path was not
  • Error 3: Social capital ≠ verification — HWI/Core tooling + endorsements made Coldcard the default
  • HWI → maintenance mode (Optech #418): ecosystem consequence of credentialed trust without seed-path audit

secsov.com/articles/dont-trust-verify · Optech #416 · Optech #418

Mining · Software

Speaking of pools that go away — GridPool vs Commons

P2Pool died (share-chain, coinbase dust). Ocean DATUM+TIDES still has an operator. Two attempts to drop the operator without a second chain:

GridPool

gridpool.net · public beta / mainnet soft launch

Not a custodial wallet, not a share-chain, not a Stratum V1 pool. High-diff proofs go into a bounded Work Set; ordinary Bitcoin blocks snapshot the payout list; you get paid only when a GridPool miner finds a real block.

  • Slot-0 = finder; rest of coinbase = snapshot. Ranked by verified PoW, not identity
  • Preferred path is DATUM → your GridPool node (Ocean-style templates, no Ocean operator)
  • Tradeoff: higher variance than FPPS/PPLNS; 300-slot coinbases break some stock firmware

Commons Pool

commonspool.org · BTCDecoded · signet, not mainnet

Same P2Pool goal — no custodian, no coordinator — without a parallel chain. Peers finalize a work snapshot at checkpoints; between checkpoints every coinbase is built from the last finalized set.

  • Miners keep template selection; coinbase pays addresses directly (claimed PPLNS)
  • Runs on Bitcoin Commons / Orange Paper, not Bitcoin Core
  • 1% fee · KYC-free · not live on mainnet

gridpool.net · commonspool.org · contrast: P2Pool · DATUM · TIDES

Discussion
  1. If GridPool still needs public seed nodes and DATUM firmware that can hash a 300-output coinbase — is the operator gone, or relocated?
  2. Commons is signet-only on a non-Core stack. Is that the honest next P2Pool, or a research demo?

Lightning · Security disclosure

Lightning — CLN Embargo Binary + LND / Taproot Assets

  • CLN 26.06.7 (Aug 28): security fixes shipped as signed binaries only — source withheld 14 days so attackers couldn't diff the patch
  • Rationale (Decker et al.): "a patch identifies the code it changes" — operators upgrade first; source later for reproducible verify
  • Embargo failed in hours: release binaries still carried debug symbols; reverse-engineering (helped by LLMs) recovered the patched source and reproduced matching checksums
  • Confirmed on Optech #420 Recap — maintainers: "big learn"; next releases ship source + binaries together
  • Also this cycle: LND v0.21; CLN 26.06 quantum-resistant channels; Taproot Assets v0.8 + Stablecoin SDK

blockstream.com/core-lightning-26-06-7 · Optech #420 · #420 Recap

Discussion
  1. If withholding source fails when debug symbols remain, what disclosure model survives LLMs?
  2. Is "upgrade now, verify later" compatible with "don't trust, verify" — or does it just relocate trust to the signing key?

Policy · DC

CLARITY Act — Cloture Failed (Sept 15)

H.R. 3633 never reached the classification fight. Bitcoin already has three labels:

CFTC

Commodity Exchange Act · McDonnell 2018

Commodity

Spot and futures. CLARITY would have given exclusive CFTC jurisdiction over Bitcoin spot markets as a “digital commodity.”

SEC

Howey · Hinman 2018

Not a security

No issuer, no common enterprise. The bill would have locked this as a digital commodity, not an investment-contract asset.

IRS

Notice 2014-21

Property

Not currency. Every sale and swap is a taxable event. Market-structure labels do not amend the tax code.

  • Senate cloture rejected 49–50 (needed 60) — roll call 234. House had passed 294–134.
  • Failed on ethics, illicit-finance / developer liability, stablecoin yield, state AG preemption — not SEC vs CFTC.

H.R. 3633 · Reuters · DLA Piper

Privacy · Critical reading · [[alloc] init]

Shielded Bitcoin — Critique

Claim: Zcash-style notes / nullifiers / ZK on L1, “no soft fork,” indexer replay; peg deferred to PIPEs v2. paper · Delving · PIPEs v2

  • Incomplete: transfer layer only; the BTC bridge (theft / inflation surface) is a different paper
  • No consensus enforcement: invalid envelopes can confirm; validity is a software convention
  • PIPEs peg is speculative: experimental witness encryption; historically TB→GB ciphertexts; heavy compute
  • Indexer liveness: can censor / delay / lie; “run your own replay” — most users won’t
  • Edge privacy fails: timing, fees, arity, carrier metadata public; peg edges kill anonymity sets
  • “No soft fork” reframes: hard problem moved into exotic crypto, not solved
Discussion
  1. Is shipping the transfer layer first a research step — or marketing an unfinished bridge?
  2. Is “Bitcoin as bulletin board + indexer” just a sidechain with OP_RETURN journaling?
